# Орда 🧟

3D екшън игра за телефон и компютър. Ордата зомбита залива града, а ти бягаш по покривите. Героят има механични ръце на раницата си и всяка от тях държи оръжие и стреля сама. Скачай от покрив на покрив, отваряй сандъци „Подобрение“, подреждай оръжията в раницата и сливай еднаквите в по-силни.

**Играй (телефон и компютър):** https://me7ko-dev.github.io/orda/

- **Хранилище в GitHub:** https://github.com/me7ko-dev/orda
- **На телефона:** отвори линка в Chrome → меню ⋮ → „Добавяне към началния екран“. Играта тръгва и без интернет.
- **За Windows:** програмата се сглобява автоматично — раздел [Releases](https://github.com/me7ko-dev/orda/releases/latest), файл `Orda-windows.zip`. Разархивирай и пусни `Orda.exe`.

## Как се играе

| | |
|---|---|
| 🕹️ Движение | на телефона плъзни пръст по екрана (джойстик), на компютъра WASD или стрелките |
| 🔫 Стрелба | механичните ръце сами се целят в най-близките зомбита |
| 🏢 Покриви | тичай до ръба на покрива и продължи натам — героят скача до съседния покрив |
| 🧟 Ордата | зомбитата вървят по улиците и се катерят по стените. Когато скочиш на друг покрив, тези по стената падат обратно |
| 🎁 Сандъци | на някой съседен покрив се появява сандък „Подобрение“. Избираш едно от три оръжия |
| 🎒 Раница | 3×3 места = до 9 ръце. Плъзни две еднакви оръжия едно върху друго и стават по-силно (по-висока редкост) |
| ⏸ Пауза | Esc или P · раница: B |

## Оръжия

Пистолет, револвер, узи, пушка, автомат, снайпер, гранатомет, ракетомет и лъчемет. Всяко има 5 редкости: обикновено, необикновено, рядко, епично и легендарно. При всяко сливане оръжието става по-силно, по-бързо и стреля по-далеч.

## Зомбита

- **Обикновени**: бавни, но са стотици.
- **Бегачи**: жълтеникави и бързи, катерят се бързо.
- **Грамадни**: червеникави, много здрави.
- **Бос**: лилав великан на всяка 4-та вълна. Като падне, оставя сандък.

## За разработка

```
npm install
npm run dev          # http://localhost:5193
npm run deploy       # сглобява и качва в GitHub Pages
node test/play.mjs   # робот играе и снима (TOUCH=1 W=412 H=860 — като телефон)
npm run models       # сваля и смалява 3D моделите (tools/models.json)
```

Направено с [three.js](https://threejs.org). Ордата е стотици анимирани зомбита наведнъж: анимацията им е „изпечена“ в текстура (vertex animation texture) и цялата орда се рисува наведнъж. 3D моделите са на Quaternius, Kay Lousberg и Kenney (CC0) — вж. [CREDITS.md](CREDITS.md).
